# Domerium

**Тема проекта:** веб-приложение для совместного ведения домашних финансов и планирования событий.

**Студент:** Килбас Эдуард
**Группа:** 453501

## О проекте

Domerium позволяет создать домашнюю группу, пригласить участников, учитывать общие доходы и расходы, планировать финансовые операции и события, просматривать календарь и историю действий. Права участника определяются его ролью в группе.

Планируемые технологии: PostgreSQL, C# и ASP.NET Core.
